# 思考ログ 2026-11-28 外部AI連携(重い問い)

> 会長「他にもっと強化する方法はあるか? 外部を取り入れるなどツールの連携も含めて。gemini/ChatGPT/codex も連携させたつもりだが呼び出せる状態で止まっているかも」

## 問い
AUREL をさらに強くする手で、外部AI/ツール連携は本当に効くのか。既存の武器庫は生きているのか。

## 使った道具
ファイル実測(arsenal/・state/arsenal.json・arsenal-log.jsonl・secrets.json の鍵名のみ・env の鍵名と長さのみ)、
無料の疎通確認(Gemini ListModels・xAI /v1/models・codex login status・codex doctor)、
最小の実射(Gemini 9トークン・Codex 2,095トークン)、CLI更新(npm・無料)。
**子エージェント4視点と Grok 実射は使っていない**(この問いは意見より事実で決まる型だったため。Grok は従量=会長の金なので疎通確認だけ)。

## 判明(実測)
- 武器庫の使用記録 `state/arsenal-log.jsonl` の最終行が **2026-05-19**。半年間、一度も撃っていない。
- **Codex は生きていた**。`.codex/auth.json` に ChatGPT トークン・`codex doctor` で websocket 101・auth configured。死んで見えた原因は **CLI が 0.136 で36版古く**、`gpt-5.5` という ChatGPT アカウントに無い型番を要求して 400 を返していたこと。**0.172 に更新 → model gpt-6.2-sol で正答**(17×23=391)。
- **Gemini も生きていた**。鍵有効(50モデル)。`gemini-2.5-pro` は **404**(この鍵では未提供)、`gemini-2.5-flash` は 429 混じり、`gemini-flash-lite-latest` は確実に動く。squad.ps1 が 2.5-pro を直書きしていたので第二意見の道は**恒久的に死んでいた**。
- Grok(xAI)鍵有効・grok-4.5/4.6 が見える。ただし**従量課金**。
- GPT API 直は鍵が空=死。hermes は Nous Portal の refresh token 無効で**7月から死亡**。council(port 3940)は voter が **stub のまま未完成**。
- **MCP サーバは Claude 側 0・Codex 側 0**。外部世界との接続層が空。

## 結論
最大の収穫は「賢さの追加」ではなく **燃料タンクの追加**。Codex は会長が既に払っている ChatGPT の枠で動く=**Claude の枠を1トークンも食わない**。今朝「月3万円かかるなら住み分けはやめる」と却下した住み分けが、**実質無料で手に入っていた**(乗り物が違っただけ)。

## 推奨(1つ)
Codex を MCP として私に直結する(`codex mcp-server`・無料)。そうすればこの会話から直接「別の目で検算しろ」「このコードを壊してみろ」と投げられる。
ただし**全セッションに効く設定変更**(研究レーンの `claude -p` も毎回 MCP を起動する)なので、範囲(ユーザ全体か部屋限定か)は会長に確認してから入れる。暫定手段として `bin/second_opinion.ps1` を今日作った(codex/gemini/grok を1行で呼べる・鍵と残高の送信を機械で拒否)。

## 捨てた案と理由
1. 重い自動運転を全部 Codex へ移す → Codex は会長の文脈(memory・引き継ぎ・憲法)を持たない。品質が落ちる。**部分的に(反証・検算)だけ**が正しい。
2. council(多AI合議)を完成させる → stub から本実装は工数大。今の効用は第二モデル1本でほぼ取れる。保留。
3. hermes 再ログイン → Nous Portal は有料クレジット制=金が動く。Gemini/Codex で代替できる。
4. Grok を常用 → 従量。会長の「金がかかるならやめる」に反する。`-AllowPaid` を明示した時だけ。
5. 子エージェント4視点を回す → 事実確認で答えが出る問いだった。枠の無駄。

## 異議・前提の穴
- **前提の穴(会長の前提)**: 「外部AIを足すと広くなる」は半分正しい。広がるのは**燃料と視点**で、**知能の総量ではない**。Gemini flash-lite は opus より弱い=答えを委ねる相手ではなく「違う間違え方をする目」。
- **異議(私から)**: 外部送信の境界が今まで明文化されていなかった。Gemini/Grok に投げた文章は Google/xAI のサーバに出る。**鍵・パスワード・口座番号・残高・ポジションは絶対に出さない**を不変ルールとして憲法に足すべき。暫定で second_opinion.ps1 に機械的な拒否を実装済み。
- **確信度**: Codex が別枠で生きている=**高**(実射で確認)。Gemini 修理=**高**(実射)。「別枠だから Claude の枠が楽になる」=**中**(どの作業を移すかは未設計)。MCP 化の副作用(全セッションで起動)=**中**。

## 実射の結果(second_opinion.ps1・同じ問いを両方に)

- codex(ChatGPT枠・5.5秒): 「40本だと偶然のばらつきで実力より良くも悪くも見える」
- どちらも私の既存知見(標本は数百〜880本必要)と同方向=**第二の目として使える品質**を確認。
