# 帝国UI「玄関」— 設計起案

> 会長の気づき（2026-08-17）:「これはダッシュボードというかもはやUIだ。指令室と同じ方法で作ったらもっとすごい」
> → 指令室の"作り方"を帝国全体へ一般化する。バラバラの画面を、同じ思想の"帝国そのもののUI"に育てる。

## 0. 結論（3行）
1. 次の背骨は **「帝国の玄関」= 全部屋を束ねる最上位の入口1枚**。
2. 作り方は指令室と同一: **Python(頭脳)が実データだけ翻訳 → 自己完結HTML → 見るだけ・金ゼロ・捏造不能**。
3. 玄関から各部屋（指令室 / 研究 / 会長室 / 生活）へ入る。部屋は同じ作り方で後から足せる。

## 1. 再利用する「作り方」= 帝国UIの憲法
- **ETLはPython側で完結** → JSは描画のみ（血を捏造できない構造）。
- **自己完結HTML** → ダブルクリックで開く。サーバ不要・外部依存なし。
- **読取専用・金ゼロ・秘密を出さない**。二重ロック / Live Gate / 会長承認権限は絶対に触れない。
- **未実装は EMPTY / FUTURE と正直表示**。飾りの動きは付けない（動きは実状態に紐づく時だけ）。

## 2. 玄関の中身（案）
- **帝国の状態を一目で**: 各事業の"生死"サイン（機関=9循環稼働 / 研究=発見数 / 会長室=要判断件数）。
- **部屋への扉**: 指令室・研究・会長室・（将来）知識の宇宙・生活。押すとその部屋のHTMLへ。
- **今日の一行**: 機関の呼吸（脈）・合計損益・要判断だけを最上段に。
- **プロップは非接触**: 玄関には出さない（別事業・さわらない境界）。出すなら別室・読取専用・g4_保護境界厳守で会長判断後のみ。

## 3. 段取り
- Phase A: 玄関1枚（静止＝その瞬間の実データ）。← 会長GOで着工。
- Phase B: 玄関＋指令室の生中継化（自動更新）。
- Phase C: 承認ボタン等（二重ロック不変）。
