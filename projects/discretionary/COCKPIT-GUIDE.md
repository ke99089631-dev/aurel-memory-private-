# 壁→壁 コックピットの読み方（会長用・2026-10-10版）

一言: **材料は「入っていい時間か」「壁は本物か」「TPはどこで止めるか」を決める助け。方向と入り方はいつもの型で決める。** 材料が型を上書きすることはない。

## 朝ブリーフ（07:06・勤務終了の直前に携帯で読む）
見るのは3行だけ。

| 行 | 読み方 | 今日の行動 |
|---|---|---|
| 予定 | 08〜12時の窓の中に「高」の指標があるか | あれば、その時刻の前後30分は新規で入らない。持っている建玉はSLが滑りやすい時間と心得る |
| 風向き | 追い風=BUY寄り / 向かい風=SELL寄り / 中立 | 型と同じ向きなら普通に。逆風なら見送るか、TPを1マス手前に |
| バイアス | AURELの当日予想（上/下/横と確信度） | 当たり率が貯まるまでは「型と同じ向きかどうか」の確認だけ。これで入る・入らないは決めない |

厚い行使価格は朝ブリーフにも出るが、チャートの紫線で見た方が早い。

## チャート（8793・「📡 材料」ボタンで一括オンオフ）
- **左下の帯**: 緑の「本物帯」なら入ってよい時間。「帯外」「ロールオーバー注意」は新規で入らない。
- **赤いカウントダウン**（左下と縦線）: 次の重要指標。残り30分を切ったら新規で入らない。
- **紫の大破線**: オプション建玉が厚い価格。右端に「建玉○万」。数字が大きいほど強い磁石・壁。
- **灰色の縦点線**: 上海開場10:00、ロンドンフィックス等。10:00前後は動きが出やすいと覚えておくだけ。
- **橙シェード（06時台）**: ロールオーバー。狭いSLが刈られる時間。窓の前なので通常は関係なし。

## 判断の順番（3手）
1. **時間**: 左下が緑で、赤いカウントダウンが30分以上先か。ダメなら待つ。
2. **型**: いつもの3条件。外壁を明確にブレイク → 床（天井）化を確認 → SLは壁の内側で狭め、TPは控えめ。ここは材料と関係なく会長が決める。
3. **微調整**: 
   - 会長の壁が紫線と重なる（±3ドル）→ その壁は信頼度が高い。
   - TPの手前に紫線がある → TPは紫線の手前に置く（次壁ぴったりを避けるのと同じ理屈）。
   - 建値とTPの間に紫線がある → そこで一度止まる前提。届かないと思えば見送り。
   - 風向きが逆 → TPを1マス手前、または見送り。

## 就寝前（12時）
建玉を持ったまま寝るなら、SLとTPが入っていることを確認する。見張り番ができるまでは、持ち越しは「SLに触れても許せる額」だけ。

## やらないこと
- 材料だけで入る（紫線があるから買う、追い風だから買う）。壁→壁の型が無いなら入らない。
- 1本の結果で材料の価値を決める。タグとして貯めて、50本で見直す。
