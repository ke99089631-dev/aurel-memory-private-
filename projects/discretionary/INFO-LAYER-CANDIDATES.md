## 着手2の実装(2026-10-10): 情報レイヤー goldinfo
- 置き場: `C:\Users\user\.aurel\goldinfo\goldinfo.py`(標準ライブラリのみ・無料・鍵不要・読取専用)
- 出力: `latest_brief.txt`(朝ブリーフ用の文章) / `oneline.txt`(台帳添付用1行) / `pack_YYYY-MM-DD.json`(事実) / `bias/`(宣言と採点) / `bias_log.jsonl`
- 定期: タスク `AUREL_GoldInfo` 毎日06:50 → `run_goldinfo.bat` → `goldinfo.py daily`(前日の採点→今日の収集)。朝ブリーフ07:05/07:06の前。
- 源: ForexFactory週間カレンダー / Yahoo(DXY・^TNX・USDJPY・GC=F) / FRED(DFII10) / CBOE遅延オプション(GLD建玉→XAU換算) / Polymarket(FRB確率) / damashi_hour_jst.json(本物帯)
- 台帳添付: `aurel_trade_room.recent_context()` が oneline.txt(36時間以内)を「成績:」行の下に添える(検証室サーバ再起動後に有効)。
- バイアス宣言→採点: `goldinfo.py bias --dir up|down|flat --conf 0.6 --why "..."` → 翌朝 `daily` が JST07:00→翌06:00 の GC=F で採点(±0.25%で上/下/横)。`stats` で通算。
- 限界: ForexFactoryは「今週」のみ=土日は翌週の予定が出ない(月曜朝に出る)。オプションは先物ベースの換算で数ドルずれ。予測市場はFRB会合のみ。
