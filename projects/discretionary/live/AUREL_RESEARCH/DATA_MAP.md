# DATA_MAP — この環境で実際に触れるデータの地図

> 補遺B2の最重要成果物。研究レーンが育てる。各領域に【実験可 / 読むだけ / 要取得】を付す。
> 「関連しそう」でなく「予測に使えるか実験できるか」で分類する。未確認は【未調査】。

## 既知（立ち上げ時の暫定・研究レーンが精査して更新）
- 金 XAUUSD M5 履歴: 【実験可】AssetEmpire `m5_loader`（少なくとも2010〜2026が計測で使えている実績・pinbar_wall/tf_compare参照）。粒度=5分OHLC。tick無し。
- 壁→壁 紙/実の台帳: 【実験可】setup_ledger.jsonl / setup_ledger_15m.jsonl / fert_reaccel_stop_ledger.jsonl / pinbar_ledger.jsonl（自分達の実験の素）。
- MT5 読取（27972608 Live / 他端末のデモ）: 【未調査→要確認】読める銘柄一覧・各銘柄の履歴可否・粒度。XAUUSD+ は現値/M5が読めている。他(指数/FX/商品)の履歴可否は未確認。
- 公開マクロ/他資産: 【要取得/未調査】ドル指数・米金利・VIX・他商品の時系列を Web で取れるか、取れても粒度/遅延/再現性は未確認。

## 未確認（研究レーンが埋める）
- MT5で履歴が引ける銘柄の全リストと各期間・粒度。
- オプション建玉/板/オーダーフロー: ほぼ無いと想定（要確認）。無ければ該当領域は「読むだけ」。
- マクロ系列の取得手段（API/CSV/Web）と時系列整合。

## 原則
- 「要取得」は、取得元・コスト・優先度・何の仮説を解くかをセットで記す。
- データが無い領域は正直に「読むだけ（検証不能）」と印をつけ、無理に実験した体を作らない。
