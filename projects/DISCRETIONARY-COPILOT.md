# 裁量トレード × AUREL 副操縦士 → 独自インジケータ化

## 会長の発言（一次情報・2026-09-19 携帯）
「裁量トレードで今検証中の形がある。今その形が期待値があるか見ている。MT5でトレードしている。AURELと連動して結果などを集めて、最終的には独自のインジケータが出せるようにしたい。どうか？」

## 前提（記憶から）
- 裁量口座 = login 27972608 / VantageTradingLtd-Live / 端末 `C:\Program Files\MetaTrader 5\terminal64.exe`（reference/mt5-terminal-separation.md）。
- Python の読取アタッチはこの端末で実証済（2026-07-11: initialize(path)→connected, account=27972608）。**端末がサーバ接続中でないと IPC は通らない**。
- 9/16 決定「接続はしない」＝頭は一つ・手と財布は別々。裁量口座は発注器の**拒否リスト**（EXECUTOR-PROPOSAL E7）。→ 本件は**読取のみ**・order_send 不使用が不変条件。
- 9/16 副操縦士の3歩（読むだけ→入る前カード→候補板）の延長線。本件はそこに「形の機械定義→インジケータ」を足す。
- 機関の検査室（edge_screen の関門: 期間外・コスト差引・FDR・時代持続）は import して使う（観察ログ 0005: 関門はコピーせず import）。
- 2026-09-19 時点で MT5 端末（terminal64.exe）は非稼働。

## 設計（起案 v0）
### 段A 読むだけ台帳（金ゼロ・自律可）
- `discretionary_journal.py`: Vantage 端末へ path 名指しで読取アタッチ → `history_deals_get` / `positions_get` で約定を取り、エントリー/エグジット前後の M1/M5 バーを同時保存 → `data/discretionary/journal.sqlite`。
- 口座ガード: login==27972608 でなければ即停止。order_send 系 API は import すらしない。
- 形のタグ付け: 会長が (a) MT5 注文コメント欄に "A" などを書く / (b) チャットで「今のは形A」と言う / (c) 後でまとめて印を付ける。
- 出力: 朝の報告に裁量成績表（本数・勝率・平均R・DD・形別）。

### 段B 形の機械定義（会長の言葉→ルール）
- 会長が形を言葉で説明（時間足・銘柄・入る条件・損切/利確の置き方・見送る条件）→ AUREL が Python でルール化 → 過去バーで検出 → **会長の実トレードと突き合わせ、一致率で定義を校正**。
- 一致率が低い＝言葉にならない感覚が残っている部分。そこを分解して定義を詰める。

### 段C 期待値の測定（二車線）
- 車線1: 会長の実トレード台帳（n 小・本物の血）。
- 車線2: 機械定義の過去検出（n 大・紙）。edge_screen と同じ関門（前70/後30・実測コスト差引・FDR・時代持続）を **import** して通す。
- 判定は数字で出す。基準は測る前に固定（結果を見て動かさない）。

### 段D インジケータ化（MQL5）
- 段C を通った定義を `.mq5` インジケータに移植（矢印・アラート・push通知）。PC の Vantage 端末に置く。
- ★ MT5 スマホアプリはカスタムインジケータを動かせない → PC 端末で走らせ、MetaQuotes ID の push 通知で携帯へ飛ばす。
- 発注は一切しない（EA にはしない）。
