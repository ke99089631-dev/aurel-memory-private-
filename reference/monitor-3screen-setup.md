# 3画面モニター構成（会長PC / Lenovo）

2026-08-18 に3枚構成が完成。今後の増設・トラブル時はここを見る。

## 配線（映像の直接口はすべて満杯）
- **PC本体 HDMI×1** … モニター1枚（直挿し）
- **PC本体 VGA×1** … モニター1枚（直挿し）
- **USB3.0 → HDMI 変換アダプター** … 3枚目＝左のDELL（縦運用）
- PC側の口: USB×4 / VGA×1 / HDMI×1。空きの直接口は無いので、3枚目は必ずUSBアダプター経由。

## 使うアダプター（確定）
- **Ainex AMC-USBHDA**（USB3.0-HDMI変換、約5,000円）。チップ=Fresco Logic **FL2000**。
- **専用ドライバー必須**。挿すだけでは映らない。
- ドライバーはアダプター内蔵ストレージにある: `E:\FL2000-2.1.36289.0.exe`（ボリューム名 VIDEODRIVER, 8MB）。
- **重要**: インストール後の**再起動を必ず通す**。前回（別アダプター）で再起動を断って映らなかった実績あり。
- 結果: 3枚・高画質・マウス残像なし・縦回転OK。

## 使わなくなった物 / 失敗例
- 最初の **1800円 MacroSilicon アダプター**（VID_534D&PID_6021, ドライバ `MSDisplay_MultiDev...exe`）は
  画質が悪くマウスが分身、縦にすると真っ暗。CPU方式の限界。→ Ainexに交換で解決。

## 切り分けで分かったこと（再発時の指針）
- 主犯は**アダプター**。**HDMIケーブルとPC性能は無関係**（PC直挿しは常に完璧に映る）。
- 「映らない/No signal」時はまず: ①ドライバー入っているか ②**再起動したか** ③USBは青い口(3.0)か。
- 縦にして消える=安アダプターの性能限界。良いアダプター(USB3.0)に替えると安定。
